# Virtual-Machine-Installation💻🛡️

## Objective
The objective of part 1 "virtual cybersecurity homelab" is to demonstrate basic installation of a type 2 hypervisor(VirtualBox) on a host operating system Windows 11, 
followed by installation of a virtual operating system(Kali Linux).

## Skills Learned

- **Operating System Basics:** how OS installation works, partitions, system resource requirements, and user setup.
  
- **Virtualization Concepts:** Built and managed a virtualized cybersecurity lab using VMware/VirtualBox/Hyper-V based on multiple security learning objectives.
  
<br>

## Tools Used
- Microsoft Windows 11 (Primary O/S)
- Virtual Box (Type 2 Hypervisor)
- Kali Linux
